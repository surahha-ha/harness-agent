## 2. 주요 발견

### A. 막힌 다음에 할 일이 없다 — 골격 1·2·6 공통 (사용자)

게이트는 판정까지만 쓰여 있고 **복구 경로**가 없다. 실제로 게이트가 꺼지는 경로가 이것이다:
막혔는데 뭘 해야 할지 모르면 사람은 규칙을 고치지 않고 **가드를 끈다.**

> 판정 메시지에 **"무엇을 하면 통과하는가"** 가 없으면 그 게이트는 결국 꺼진다.

### B. ⭐⭐ 역할을 나누면 컨텍스트가 끊긴다 — 골격 3 (숙련자)

3원칙은 **정보 손실을 대가로** 독립성을 산다. 설계자가 본 것을 집행자는 못 보고,
작성자가 확인한 것을 판정자는 모른다. 그런데 **역할 간 인계 산출물의 형식이 없다.**

경계만 있고 인계가 없으면 각 역할이 같은 조사를 다시 하거나, 더 나쁘게는 **안 하고 넘어간다.**
이건 골격 3 을 실제로 무너뜨리는 지점이다.

### C. 도입 전략이 없다 — 골격 2·6 (사용자·숙련자)

기존 코드베이스에 켜면 **첫날 전부 막힌다.** grandfather(기존 위반은 통과) 개념이
골격 5 에만 있고 2·6 에는 없다. 골격 2 는 `--audit` 으로 세는 것까지만 있고,
**세고 나서 무엇을 하는지**가 없다.

### D. 슬롯을 채우는 판별 질문이 없다 — 전 골격 (일반인)

3종 세트 ②(채우는 절차)가 실제로는 **"무엇을 넣는가"** 수준이고 **"어떻게 정하는가"** 가 없다.
`{파괴 명령 패턴}` 을 처음 채우는 사람은 무엇이 파괴적인지 판정할 기준이 없다.

### E. 가드 미설치를 아무도 감지 못 한다 — 골격 1·2 (숙련자)

"가드가 죽으면 보이게 한다" 는 있는데, **아예 설치되지 않은 경우**는 잡히지 않는다.
훅 경로 설정을 한 번 안 하면 게이트 전체가 조용히 없는 상태가 된다 — 그리고 그건 통과와 구별되지 않는다.

### F. 경고 피로 — 골격 4 (사용자)

같은 경고가 매 번 뜨면 읽지 않게 되고, 곧 끈다.
**승인된 차이**(의도된 비대칭)와 **새 차이**를 구분하지 못하면 감시 도구는 소음이 된다.

### G. 한계를 스스로 밝히지 않는다 — 골격 1·2·7 (전문가)

- 골격 1 의 패턴 판정은 변수 치환·개행으로 우회된다. **보안 경계가 아니라 실수 방지**인데 그렇게 안 쓰여 있다.
- 골격 2 의 테스트 존재 판정은 **테스트가 의미 있는지는 보지 않는다.**
- 골격 7 은 배포 채널 형태를 특정 방식으로 가정한다.

한계를 안 쓰면 읽는 사람이 **보증으로 오해**한다. 오해된 보증은 없는 것보다 나쁘다.

### H. 승인 주체가 없다 — 골격 1·6·7 (관련자)

"승인을 받는다" 는 있는데 **누구에게** 가 없다. 슬롯도 없다.

## 3. 분류

### 내가 고친 것 (이번 반영)

| # | 발견 | 반영 |
| - | - | - |
| A | 복구 경로 부재 | 전 게이트 골격에 **복구 경로** 항목 추가 — 판정 메시지가 "무엇을 하면 통과하는가" 를 포함해야 한다 |
| C | 도입 전략 부재 | 골격 2·6 에 **단계적 도입** 절차 추가(측정 → 기존분 유예 → 신규분 적용 → 승격) |
| D | 판별 질문 부재 | 슬롯마다 **채우는 판별 질문**을 명시하도록 골격 규약에 추가 |
| E | 미설치 미감지 | 골격 1·2 에 **활성 확인** 항목 추가 |
| F | 경고 피로 | 골격 4 에 **승인된 차이와 새 차이의 구분** 추가 |
| G | 한계 미서술 | 골격 1·2·7 에 **한계** 항목 추가 |
| H | 승인 주체 부재 | 슬롯 `{승인 주체}` 추가 |

### 사람이 정한 것 (확정)

| # | 결정 | 근거 |
| - | - | - |
| **P1** | **되돌릴 수 없는 것은 처음부터 `deny`** | 전부 `ask` 로 시작하는 방식은 **승격 절차를 실제로 돌리지 않으면 영원히 `ask` 에 고착**되고, 사람은 습관적으로 승인하게 된다. 그 사이 치명적 사고를 한 번 허용하는 셈이다 |
| **P2** | **경량 경로를 둔다 — 위험도 기준.** 단 **진입 조건이 아니라 탈락 조건**으로 | 변경 크기와 위험은 상관이 약하다(한 줄이 가장 위험한 경우가 많다). 그런데 "저위험이면 경량" 은 자기평가가 되고 사람은 자기 변경을 언제나 저위험으로 본다 → **"하나라도 걸리면 전체"** 형태로 뒤집는다. 경량으로 갔다는 사실은 보고에 남긴다 |
| **P3** | **인계는 체크리스트.** 단 **미검증 범위만 필수**, 나머지 셋은 권장 | 스키마 확정은 이르다 — 인계를 한 번도 실제로 안 돌려봤다(골격 7 의 "두 번째 채널 전엔 일반화 않는다" 와 같은 논리). 그리고 네 항목의 무게가 다르다: **"안 본 것" 만이 복원 불가**하고, 나머지는 산출물에서 대체로 복원된다. **"미검증 범위: 없음" 도 명시하게 한다** — 빈칸은 안 쓴 것이고 "없음" 은 판단한 것이다 |

### 알고도 안 고친 것

- **패널을 매 골격 변경마다 돌리지 않는다.** 다섯 렌즈 전체는 비싸다.
  골격 **신설**과 **절차 변경**에만 돌리고, 문구 수정에는 돌리지 않는다.
- **골격 7 의 배포 채널 일반화는 미룬다.** 실제 두 번째 채널을 만나기 전에는
  무엇이 공통인지 알 수 없다 — 지금 일반화하면 상상으로 슬롯을 판다.
